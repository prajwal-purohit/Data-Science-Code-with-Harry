## 📌 About

This repository contains my notes, code, and project work from **The Ultimate Job Ready Data Science Course** by **CodeWithHarry**.

The course covers the full data science stack — from Python fundamentals through statistics, SQL, machine learning, deep learning, and a capstone RAG-based AI project.

## 🎯 What You'll Learn

- Master Python programming from a data science perspective
- Perform powerful data analysis using Pandas and NumPy
- Create data visualizations with Matplotlib and Seaborn
- Understand and apply core statistics and probability concepts
- Clean and preprocess real-world datasets for accurate insights
- Build real-life projects end-to-end
- Use Jupyter Notebooks for data-driven development
- Work with developer tools like Quadratic AI (included free with the course)
